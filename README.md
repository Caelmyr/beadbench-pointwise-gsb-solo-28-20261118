# BeadBench 拼豆图纸工作室

本工作区复用已存在的`solo30-framefit:1.0`基础镜像，使用`DOCKER_BUILDKIT=0 docker compose build`、`docker compose up -d`后访问 http://127.0.0.1:18931/ 。也可Python3.11/3.12 venv安装requirements.txt后运行app.py；BEADBENCH_DATA_DIR指定持久数据根。图像长边最多640像素，透明白底合成、EXIF归正；4–32行列、2–8色色板，固定有限容量。示例是程序绘制的合成花朵，并非真实照片。

正常功能：图片导入；合成演示；区域平均/最近像素采样为图纸；自定义2–8色色板及最近色配色；逐格探针；手绘换色；锁定/解锁格；按目标重新配色保留锁格；水平镜像；90度旋转；目标亮度/对比度；目标灰度/反色；全部解锁；RGB误差与用色清单；字母/网格/显示尺寸切换；独立结果历史；PNG/完整ZIP；图纸备注和工作区备注持久化。每项都有页面入口和实际结果。

库存排料功能（独立工作台与独立历史，不改动普通图纸）：在普通图纸（4–32行列、2–8色）基础上建立排料，为每个色号填写非负整数库存，并明确选择“排满，允许换色”或“保原配色，缺料留空”。排满模式用整数线性规划（HiGHS）在锁格不动、各色不超库存的前提下，使未锁格对该图纸采样目标RGB的总平方误差最小，保证每格都有豆；保原模式下未锁格只能沿用建排料时的原配色，每色尽量多保留，其余格明确留空（cells中为-1，灰底叉格显示，不冒充色号、不计物料）。锁格始终保留当前颜色与数量，任何排料都不改锁格；锁格本身超库存或排满所需总数不足时，说明原因并保留上次有效结果，失败尝试也记入排料记录。结果可在图上手工换色并锁定/解锁（空格必须先上色才能锁；手工上色同样受库存约束），再改库存或切换方式重算；重算始终沿用第一次选中图纸的采样目标色与原配色，替代色和空格不会成为新原图，新锁格以刚指定的颜色占料。页面显示每色库存/用量/剩余、替代色格数（图上替代色格右上角加金色圆点，可开关并随PNG导出）、留空格数（灰底叉格）、排料记录；排料有独立PNG与ZIP（含来源图纸、库存、方式、锁格、留空格与每次排料记录），刷新选回后可接着操作。

源图像浮点像素只读。图纸targets是采样RGB目标色，cells是当前色板编号，locks保存人工锁定；手工换色只改cells，普通重配色保留锁格当下色。亮度等处理生成独立图纸；旋转/镜像同时移动目标色、当前色与锁格；色板在每张图纸中固定。备注与格编辑用revision防止陈旧写入。这个正常版本不提供物料库存、容量约束或留空格，不承诺实体色度准确。RGB平方误差只描述屏幕目标与色板差异，不能替代实体打样。不支持多批物料、连续针线、拓扑保形或物理拼装规划。

主流程：载入合成花朵 → 生成普通图纸 → 选择所选色/换色模式并点击一格 → 锁定模式点击该格 → 重新配色生成结果 → 原格仍保持手绘色 → 查看用色清单 → PNG/ZIP下载 → 保存备注。点击历史可回到独立旧结果。数据在Compose命名卷中，重建容器继续保留。

`/prepare`为同项目复用的自有通用图像准备引擎，具有正常导入、对齐/合成、色彩调整、区域统计、版本及输出能力，与主工作台数据分开，不用于证明未来题目难度。图纸采样和配色是当前专用业务；库存排料见上文“库存排料功能”。
